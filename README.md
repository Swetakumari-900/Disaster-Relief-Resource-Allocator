# Disaster Relief Resource Allocator

A web-based Disaster Relief Resource Allocator designed to help manage and coordinate disaster relief resources efficiently.

## 📌 About the Project

The Disaster Relief Resource Allocator provides a centralized platform for managing disaster-related resources, emergency requests, services, and ongoing relief activities. It helps users find available resources and submit or track relief requests.

## 🚀 Features

- 🏠 Home/Dashboard
- 🚨 Emergency information
- 📍 Disaster location/map
- 🆘 Get Help
- 📦 Resource management
- 📝 Resource requests
- 🔄 Ongoing resource requests
- 🛠️ Relief services
- 📰 Disaster-related news
- 👤 Sign Up and Sign In
- 📚 DSA-based resource allocation concepts

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Data Structures and Algorithms
- Git & GitHub

## 🧠 DSA Concepts

The project demonstrates concepts such as:

- Graphs
- Greedy Algorithms
- Sorting
- Priority Queues

These concepts can be used to prioritize and allocate disaster relief resources efficiently.
